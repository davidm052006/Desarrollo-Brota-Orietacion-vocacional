Rama docker-brota · Windows + WSL 2

Brota en tu computador, paso a paso.

Instala lo necesario una vez, clona los repositorios y arranca la demo web o la vista móvil con comandos make. No necesitas instalar Node.js ni Flutter en Windows para estas demos Docker.

Antes de comenzar

Qué vas a instalar y qué vas a abrir

Windows aloja Docker Desktop. Ubuntu dentro de WSL 2 ejecuta los comandos. Las páginas se abren en el navegador normal de Windows mediante 127.0.0.1.

Windows→Ubuntu / WSL 2→Docker + Supabase local→Navegador

Web · React

Frontend en 5174, API en 3001 y Supabase local.

Móvil · Flutter

Vista Flutter compilada para navegador en 5175. Puedes verla con tamaño de teléfono.

Una sola base localWeb y móvil comparten backend, usuarios y datos de Supabase. La vista móvil en Docker no es un emulador Android ni genera una app instalable.
Paso 1 · En Windows

Instalar WSL 2 y Ubuntu

  1. Abre PowerShell como administrador

    En Inicio, busca PowerShell, haz clic derecho y elige Ejecutar como administrador.

    PowerShell · administrador 
    wsl --install -d Ubuntu

    Reinicia Windows si te lo solicita. En el primer inicio de Ubuntu crea tu usuario y contraseña de Linux; al escribir la contraseña no se muestran caracteres.

  2. Comprueba la versión

    PowerShell 
    wsl --update
wsl -l -v

    Ubuntu debe aparecer con VERSION 2. Si aparece 1, ejecuta wsl --set-version Ubuntu 2 en PowerShell y espera a que termine.

  3. Entra a Ubuntu

    Busca Ubuntu en Inicio o escribe esto en PowerShell:

    PowerShell 
    wsl -d Ubuntu
Las instrucciones con etiqueta PowerShell van en Windows. Las de Ubuntu · WSL van dentro de la ventana de Ubuntu.
Paso 2 · En Windows

Instalar y conectar Docker Desktop

  1. Instala Docker Desktop

    Descárgalo desde la página oficial de Docker. Elige el motor WSL 2 y abre Docker Desktop. Espera a que indique que el motor está funcionando.

  2. Activa la integración con Ubuntu

    En Docker Desktop abre Settings → Resources → WSL Integration, activa Ubuntu y pulsa Apply & restart. En Settings → General, comprueba que esté seleccionado el motor WSL 2. Usa contenedores Linux.

  3. Verifica desde Ubuntu

    Ubuntu · WSL 
    docker --version
docker compose version
docker info

    Si docker info muestra información del servidor, la conexión funciona. Mantén Docker Desktop abierto al usar Brota.

No instales otro Docker Engine dentro de UbuntuDocker Desktop ya proporciona el motor a WSL 2. Dos motores pueden causar conflictos.
Paso 3 · En Ubuntu

Preparar los comandos de desarrollo

Instala Git, Make y curl. Ubuntu te pedirá la contraseña de Linux que creaste en el primer inicio.

Ubuntu · WSL 
sudo apt update
sudo apt install -y git make curl

Instalar Supabase CLI para Linux

Los scripts de Brota llaman a supabase directamente desde Ubuntu. Este paquete fija la versión 2.114.0, usada al comprobar esta guía, y corresponde a Ubuntu x86_64.

Ubuntu · WSL · x86_64 
uname -m
curl -fL -o /tmp/supabase_2.114.0_linux_amd64.deb https://github.com/supabase/cli/releases/download/v2.114.0/supabase_2.114.0_linux_amd64.deb
sudo apt install -y /tmp/supabase_2.114.0_linux_amd64.deb
supabase --version

El primer comando debe mostrar x86_64. Si muestra aarch64, busca el paquete linux_arm64.deb de esa versión en las versiones oficiales antes de instalar.

Paso 4 · En Ubuntu

Clonar web y móvil como carpetas hermanas

Guarda el código dentro de Ubuntu, por ejemplo bajo ~/proyectos. La demo móvil necesita encontrar brota-flutter al lado de brota-web.

Ubuntu · WSL 
mkdir -p ~/proyectos/brota
cd ~/proyectos/brota
git clone -b docker-brota https://github.com/davidm052006/Desarrollo-Brota-Orietacion-vocacional.git brota-web
git clone -b develop https://github.com/davidm052006/brota-flutter-app.git brota-flutter
cd brota-web
pwd
~/proyectos/brota/
├── brota-web/  ← ejecuta make aquí
└── brota-flutter/  ← código de la vista móvil

Si GitHub pide acceso, solicita permiso al responsable del repositorio. La ruta final de pwd debe terminar en /brota-web.

Dos repositorios, dos ramasLa configuración Docker y esta guía están en la rama docker-brota del repositorio web. El repositorio móvil se clona desde su rama develop. Puedes consultar la rama Docker de Brota en GitHub.
Paso 5 · Git básico

Ver y cambiar de rama sin perder trabajo

Cada repositorio tiene sus propias ramas. Haz estos comandos dentro de brota-web o brota-flutter, según el proyecto que quieras cambiar.

Ubuntu · WSL · dentro del repositorio 
git status
git branch --show-current
git fetch origin
git branch -a

Para volver a la rama de Docker en brota-web y traer los cambios publicados:

Ubuntu · WSL 
git switch develop
git switch docker-brota
git pull --ff-only

En brota-flutter, usa git switch develop y git pull --ff-only para actualizar su rama de trabajo.

Si la rama solo existe en GitHub, créala localmente una vez. Sustituye nombre-de-rama por el nombre que te indique el equipo:

Ubuntu · WSL 
git switch --track origin/nombre-de-rama
Si git status muestra archivos modificadosNo cambies de rama ni ejecutes comandos de borrado a ciegas. Confirma primero con el equipo qué hacer con tus cambios. git pull --ff-only evita crear un merge inesperado.
Paso 6 · La demo

Iniciar Brota

Abre Docker Desktop, entra a Ubuntu y colócate en el repositorio web:

Ubuntu · WSL 
cd ~/proyectos/brota/brota-web

Iniciar web

Arranca Supabase, el backend y React.

Ubuntu · WSL 
make demo-brota-up
Abrir web →

Iniciar vista móvil

Necesita ambas carpetas hermanas. Arranca el backend y compila Flutter para navegador.

Ubuntu · WSL 
make demo-brota-movil-up
Abrir móvil →

Puedes ejecutar ambos comandos si quieres comparar las dos interfaces. make brota-demo-up es un alias de make demo-brota-up. La primera descarga de imágenes y la primera compilación Flutter pueden tardar varios minutos. Cuando make termine y vuelva el cursor, abre los enlaces en el navegador de Windows.

Para ver la vista móvil como teléfonoEn Chrome o Edge, pulsa F12, activa el icono de dispositivo y elige un tamaño de teléfono. El contenedor sirve Flutter Web; no instala una APK ni inicia un emulador.

Paso 7 · Trabajo diario

Consultar, reiniciar datos y detener

Qué quieres hacerComando desde brota-web
Ver direcciones y cuentas webmake demo-brota-info
Ver direcciones de la vista móvilmake demo-brota-movil-info
Comprobar contenedoresdocker ps
Recrear los datos ficticiosmake brota-demo-reset
Detener la demo localmake brota-demo-down

make brota-demo-info es un alias de make demo-brota-info. Las cuentas locales preparadas para la demo son admin.demo@brota.local y estudiante.demo@brota.local; la contraseña de ambas es Demo123!.

El reset borra cambios locales de la basemake brota-demo-reset vuelve a aplicar migraciones y datos ficticios. Para detener sin reiniciar los datos usa make brota-demo-down. Nunca uses respaldos privados como seed.

Para volver otro día: abre Docker Desktop, abre Ubuntu, ejecuta cd ~/proyectos/brota/brota-web y luego el comando make de la interfaz que necesites.

Ayuda rápida

Si algo falla

“make: command not found”

Estás en Ubuntu y falta Make. Ejecuta sudo apt update y sudo apt install -y make. Si estás en PowerShell, abre Ubuntu: wsl -d Ubuntu.

“docker: command not found” o no conecta al daemon

Abre Docker Desktop y revisa Settings → Resources → WSL Integration → Ubuntu. Comprueba wsl -l -v en PowerShell: Ubuntu debe ser versión 2. Luego vuelve a Ubuntu y ejecuta docker info. Tras cambiar la integración, cierra Ubuntu y ejecuta wsl --shutdown en PowerShell antes de abrirlo de nuevo.

“supabase: command not found”

Instala el paquete Linux de Supabase CLI del paso 3 dentro de Ubuntu. Instalar la versión Windows no pone el comando en la terminal Ubuntu.

“No se encontró ../brota-flutter”

Revisa la estructura del paso 4. Las carpetas brota-web y brota-flutter deben estar al mismo nivel; usa exactamente esos nombres.

“No rule to make target demo-brota-movil-up”

Comprueba pwd y git branch --show-current. Debes estar en brota-web, rama docker-brota. Si ya tienes una copia antigua, ejecuta git fetch origin y git switch --track origin/docker-brota; si la rama local ya existe, usa git switch docker-brota y git pull --ff-only.

Un puerto ya está ocupado o la página no abre

Ejecuta docker ps y comprueba que no haya otro proyecto usando los puertos 3001, 5174, 5175 o 55321–55327. Para la API prueba 127.0.0.1:3001/api/health. Consulta los logs con docker compose -f compose.brota-demo.yml logs --tail=80 backend frontend; para Flutter, docker logs --tail=80 brota-demo-mobile-1.

¿Dónde veo los archivos Linux desde Windows?

Desde la carpeta del proyecto en Ubuntu ejecuta explorer.exe .. Se abrirá el Explorador de Windows en esa ubicación. Trabaja con Git y Make desde Ubuntu para conservar el rendimiento de WSL.
